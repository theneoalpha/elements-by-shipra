Design and generate a complete, premium, modern website for a luxury interior design studio called:

SHIPRA DESIGNS
Interior Design Studio

The website is for a professional interior design studio based in Bilaspur, Chhattisgarh, India.

IMPORTANT:
Do NOT create a generic interior-design website.
Do NOT use the typical modern website patterns such as repetitive rectangular cards, excessive glassmorphism, gradient blobs, generic testimonial cards, or a grid of service cards.

Create an original, art-directed website with a sophisticated architectural/editorial aesthetic.

The website should feel like a premium interior architecture studio — elegant, minimal, warm, confident and highly visual.

--------------------------------------------------
BRAND / VISUAL DIRECTION
--------------------------------------------------

Overall personality:

• Luxury
• Modern
• Architectural
• Editorial
• Warm
• Minimal
• Sophisticated
• Human
• Timeless

Use a refined neutral palette:

• Warm ivory / off-white
• Soft beige
• Sand
• Taupe
• Charcoal / near-black
• Muted bronze / champagne gold as an accent

Do NOT make the entire website dark.

Use mostly light sections with occasional dark sections for contrast.

Typography should combine:

• Elegant high-contrast serif typography for major headings
• Clean modern sans-serif for body text and navigation
• Very limited handwritten/script typography only where it adds personality

Use generous whitespace.

Use thin dividers, subtle borders, elegant numbering, asymmetric layouts, curved architectural shapes and editorial compositions.

Avoid excessive shadows.

Avoid excessive rounded cards.

Avoid making every section look like a collection of cards.

The website should feel custom-designed rather than template-based.

--------------------------------------------------
RESPONSIVE DESIGN
--------------------------------------------------

Design both:

1. Large desktop screens
2. Mobile screens

Do NOT simply shrink the desktop layout for mobile.

Create intentional responsive compositions.

On mobile:

• Preserve the visual identity
• Keep typography elegant
• Use vertical storytelling
• Avoid horizontal overflow
• Use swipe interactions where appropriate
• Keep important content immediately visible
• Simplify navigation into a premium mobile menu
